# Maximalist Agency - Creative Redesign

A high-energy, bold, and modern creative agency website template. This project is a cutting-edge redesign of the "Leon" template, drawing inspiration from acid-house aesthetics, brutalist web design, and high-fashion digital editorials.

## 🚀 Aesthetic Direction

- **Vibe**: High-energy, bold, and unforgettable.
- **Core Goal**: Transform a generic template into a cutting-edge showcase for creative professionals.
- **Visual Identity**: Obsidian Black background with high-contrast Acid Green, Electric Cyan, and Hot Pink accents.

## ✨ Key Features

- **Maximalist Design**: Large typography, bold colors, and high-impact visual statements.
- **Infinite Marquee**: Continuous scrolling text dividers (Services, Portfolio, About, Contact) to maintain visual energy.
- **Asymmetrical Grid**: A staggered, "broken" grid layout for Services and Portfolio sections.
- **Responsive Layout**: Fully functional across mobile, tablet, and desktop devices.
- **Modern Typography**: Uses a mix of `Syne` for headings, `Space Mono` for technical labels, and `Inter` for body text.
- **Custom Header**: A minimalist navigation with a hidden checkbox-triggered mobile menu.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better accessibility and SEO.
- **CSS3**: Advanced CSS including variables, Flexbox, Grid, and keyframe animations.
- **Normalize.css**: Ensures consistent rendering across different browsers.
- **Font Awesome**: High-quality icons for services and social links.
- **Google Fonts**: Integration of Syne, Space Mono, and Inter.

## 🏁 Getting Started

To view the project locally:

1. Clone the repository or download the source code.
2. Open `index.html` in your preferred web browser.

No build tools or external dependencies are required for basic viewing.
